# Contributing to Kingpost

## Open an issue

Choose the repository closest to the change. For a website correction, include the page URL and the text or behavior you want to change. For a Stow issue, describe the warehouse task you were trying to complete.

Search existing issues first. If you find a match, add any details that would help someone reproduce the problem or understand your use case.

## Submit a pull request

Follow the setup instructions in the repository's README. Describe what you changed, link the relevant issue if there is one, and explain how you checked the result. For a visible change, a screenshot can help reviewers verify it. Use sample warehouse data in screenshots and examples.
